ทำไม Windows ถึงขึ้น “Windows protected your PC”?

หน้าต่างนี้เป็นระบบ SmartScreen ของ Windows ที่เตือนทุกครั้งเมื่อเปิดโปรแกรมที่ยังไม่มีลายเซ็นดิจิทัลจากผู้เผยแพร่ที่ Windows รู้จัก และยังไม่มีคนโหลดไปรันมากพอ เกมนี้ทำโดยนักพัฒนาอิสระและยังไม่ได้ซื้อใบรับรองรับรอง (ซึ่งมีค่าใช้จ่ายรายปี) คำเตือนนี้เป็นเรื่องของชื่อเสียงไฟล์ ไม่ได้แปลว่าตรวจพบมัลแวร์

ถ้าคุณไม่สบายใจ ไม่ต้องติดตั้ง ใช้ขั้นตอนตรวจสอบไฟล์ด้านล่างก่อนได้

ขั้นที่ 1 กดที่ “More info”

Windows protected your PC

Microsoft Defender SmartScreen prevented an unrecognized app from starting.
More info
ถ้าเป็นภาษาไทยจะเป็นคำว่า “ข้อมูลเพิ่มเติม”
ขั้นที่ 2 กด “Run anyway”

Windows protected your PC

App: KaDuekBanRang-Setup.exe
Run anyway Don’t run
หลังจากนั้นทำตามตัวติดตั้งปกติ ไม่ต้องใช้สิทธิ์แอดมิน

ใช้ Windows 11 แล้วโดนบล็อกเลย ไม่มีปุ่ม Run anyway? เป็นเพราะโหมด Smart App Control ที่บล็อกโปรแกรมที่ไม่ได้เซ็นและยังไม่มี reputation ถ้าไม่อยากปิดโหมดนี้ ให้เล่นเวอร์ชันเบราว์เซอร์แทน (ถ้ามีปุ่มด้านบน)

ตรวจสอบว่าไฟล์ปลอดภัย

1. เทียบค่า SHA256 เปิด PowerShell ในโฟลเดอร์ที่โหลดไฟล์ แล้วรัน

Get-FileHash .\KaDuekBanRang-Setup.exe -Algorithm SHA256

ค่าที่ได้ต้องตรงกับค่านี้ ถ้าไม่ตรง อย่าติดตั้ง และโหลดใหม่จากหน้านี้เท่านั้น

2. ดูผลสแกนไวรัส

3. ติดตั้งแบบปลอดภัยต่อเครื่อง ตัวติดตั้งไม่ขอสิทธิ์แอดมิน ลงในโฟลเดอร์ของคุณเอง ถอนการติดตั้งได้จาก Settings → Apps

คำถามที่พบบ่อย

ทำไมไม่เซ็นรับรองไฟล์ให้หายเตือน?

ใบรับรองสำหรับเซ็นโปรแกรมมีค่าใช้จ่ายรายปี และบริการราคาถูกบางตัวจำกัดประเทศ แม้เซ็นแล้วคำเตือนก็ไม่หายทันที ต้องสะสมคนโหลดก่อน ตอนนี้จึงใช้วิธีเปิดเผยค่า SHA256 และผลสแกนแทน

ถอนการติดตั้งยังไง?

Settings → Apps → Installed apps → กะดึกบ้านร้าง → Uninstall

ต้องต่ออินเทอร์เน็ตไหม?

ไม่ต้อง ภาพและเสียงทั้งหมดอยู่ในตัวเกม
